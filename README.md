# Tn-seq Domain Essentiality Visualiser

This project aims to develop a reproducible bioinformatics workflow for visualising bacterial gene essentiality data at the protein domain level.

The workflow will integrate:

1. Tn-seq insertion or essentiality data
2. bacterial genome annotation files
3. protein domain annotation data

The final output will include automated tables and visualisations showing whether essential regions within genes overlap with annotated protein domains.

## Project status

This repository is currently under development as part of an MSc Bioinformatics research project.

## Planned outputs

- A reproducible analysis pipeline
- Cleaned and processed example datasets
- Domain-level essentiality summary tables
- Static visualisations of selected genes
- Interactive or browser-compatible visualisation outputs
- Documentation explaining how to run the workflow

## Data sources

Raw datasets are not currently included in this repository. Download links, database sources, and file descriptions will be documented in `docs/data_inventory.md`.
